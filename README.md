# Projects Repository

Welcome to my Projects Repository! This repository contains various projects that I've worked on across different branches. Each project is organized into its own branch for easy access and navigation.

## Projects Overview

### 1. **VTube (YouTube Clone)**

- A YouTube clone built using React for the frontend, Django for the backend, and MongoDB for data storage.
- Key features:
  - JWT Authentication for secure login.
  - Video upload, streaming, and real-time updates.
  - User engagement improvement through persistent authentication.

### 2. **Portfolio**

- A personal portfolio built to showcase my skills, experience, and projects.
- Built with React, and hosted using Vercel for a seamless and responsive user experience.

### 3. **Music Player**

- A dynamic music player app with custom playlists, built using React.
- User-friendly interface with play, pause, and skip functionality.

### 4. **Grid Assignment**

- A React-based project to implement and demonstrate complex grid layouts and responsiveness.

### 5. **GitHub User Viewer**

- An app to view GitHub users and their repositories by fetching data from the GitHub API.
- Built using React with search functionality to quickly find users and their information.

### 6. **Sculpt Fitness**

- A fitness website built to provide workout plans and nutritional advice.
- Focused on user engagement with dynamic content and interactive features.

### 7. **Visualize MERN Project**

- A full-stack MERN project designed to visualize data in real-time.
- Built using MongoDB, Express.js, React, and Node.js.

### 8. **QnA Langchain Chatbot**

- A chatbot application built using Langchain and ChatGPT, allowing users to ask questions based on documents and online sources.

### 9. **DocGPT**

- A document analysis tool built with React and Django, with ChatGPT integration for analyzing documents and providing insights.

### 10. **Employee Management System (EMS)**

- A system for managing employee data, built using React and Node.js.
- Includes CRUD functionality, JWT authentication, and MongoDB for data storage.

### 11. **Visitor Management System**

- A React and Node.js based application to manage visitor logs for organizations.

### 12. **EMS using React and SQL**

- Another variant of the Employee Management System, this time using React and SQL for backend data handling.

### 13. **Shopping App (CUI) using Tkinter and MySQL**

- A console-based shopping application built with Python's Tkinter for the GUI and MySQL for data management.

### 14. **Employee Management System (CUI) using Tkinter**

- A console-based system for managing employee information using Python's Tkinter for the UI.

### 15. **Vote Webapp**

- A web application for online voting, allowing users to securely cast their votes.

### 16. **Selenium Web Scraping**

- A project utilizing Selenium to scrape data from websites and organize it for analysis.

### 17. **Spam/Ham Mail Checker**

- A machine learning project to classify emails as spam or ham using Python.

### 18. **Data Visualization Website**

- A website built for visualizing data interactively using React and D3.js.

### 19. **Helpdesk Chatbot**

- A chatbot application designed to handle helpdesk queries efficiently.

## How to Access Projects

Each project is organized in its own branch. You can switch between branches to access the individual projects. Here’s how you can do it:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/vedanthelwatkar/Projects.git
   git branch -r
   git checkout <branch-name>
   ```
